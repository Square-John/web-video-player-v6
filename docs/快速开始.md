# 快速开始

本指南用于在本机安装、配置、启动和首次使用 Web Video Player。需要 Node.js 20 或更高版本、npm 和现代浏览器。

## 1. 安装依赖

在仓库根目录执行：

```bash
npm --prefix client install
npm --prefix server install
```

根 package 只提供编排命令，前端和后端依赖分别安装在各自 package 中。

## 2. 三份配置

所有可编辑配置都在根 `config/`，前后端分开但只有一套场景无关配置：

| 文件 | 作用 | 修改后生效方式 |
|---|---|---|
| `config/project.config.js` | 本地开发启动选择与联合进程管理 | 重新执行启动命令 |
| `config/frontend.config.js` | 浏览器后端地址、Vite host/port、构建 basePath | runtime 可在构建产物中修改后刷新；开发/构建项需重启或重建 |
| `config/backend.config.js` | Node 监听、允许前端 Origin、可信代理、日志和安全限制 | 重启后端 |

不要新增 `.env`、命令行覆盖或第四份配置。配置非法会在任何服务启动前失败。

## 3. 启动

```bash
npm run dev
```

`dev` 根据 `ProjectConfig.startup` 工作：

- `selectionMode: 'configured'`：直接采用 `target`。
- `selectionMode: 'manual'`：交互终端询问启动前端、后端或全部。
- `target: 'all'`：默认同时启动前后端。
- `openBrowser: true`：前端就绪后打开浏览器。

也可以显式执行：

```bash
npm run dev:frontend
npm run dev:backend
npm run dev:all
```

默认前端地址为 `http://localhost:5173`，后端由前端配置连接 `http://localhost:3000`。只启动前端时，页面可以打开，但真实 Provider 信息请求会失败；项目不会回退模拟数据。

## 4. 首次打开

首次打开会初始化 IndexedDB、安装当前内置 Provider，并恢复设置、收藏、历史和活动数据源。初始化失败时应用显示启动失败界面，不要求清理浏览器数据。

建议依次检查：

1. 导航栏出现可用数据源。
2. 首页、电影、电视剧和搜索能显示当前源内容。
3. 详情页能显示线路和选集。
4. 播放页可以探测并播放浏览器可直连媒体。
5. 设置 → 数据源管理可以检查、启停和导入 Provider。

## 5. 导入自定义 Provider

进入“设置 → 数据源管理 → 导入数据源”，选择文件、粘贴文本或 HTTPS 地址。平台先静态预览，不执行脚本；确认 SHA-256、作者、站点、能力和 host 后才执行并保存。

开发脚本请先阅读 [数据源脚本开发指南](数据源脚本开发指南.md) 和 [前端展示能力与字段契约](前端展示能力与字段契约.md)。

## 6. 生产验证和构建

```bash
npm run build
```

该命令执行前端完整生产构建和后端生产入口检查。单独构建：

```bash
npm run build:frontend
npm run build:backend
```

前端静态产物位于 `client/dist/`。本地预览前端：

```bash
npm run preview:frontend
```

生产方式启动后端：

```bash
npm run start:backend
```

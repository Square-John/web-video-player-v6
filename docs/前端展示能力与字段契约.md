# 前端展示能力与字段契约

本文面向数据源脚本作者和前端集成者，说明 Web Video Player 每个页面会发出什么标准请求、消费哪些标准字段，以及字段缺失、请求失败和内容过期时如何展示。

本文是公开版页面展示与标准字段说明；Proxy Protocol、Provider ABI 和 manifest 的机器可验证边界见 [`contracts/current`](../contracts/current/)。具体脚本接入流程见 [数据源脚本开发指南](数据源脚本开发指南.md)。

## 1. 接入边界

- Provider 负责源站地址、请求、会话、挑战、解析、字段清洗和业务错误判断。
- 页面、Store 和通用 Service 只消费标准对象，不读取源站原始字段或按站点身份分支。
- Provider 通过 `fetchData(request)` 提供内容，通过 `fetchFilterMeta(request)` 提供电影/电视剧筛选项。
- `sourceId + ContentItem.id` 是平台内同一内容的稳定身份；页面不会从标题或媒体 URL 猜测身份。
- 字段为空时按本文约定隐藏或回退，Provider 不应填写“暂无”“未知”等占位字符串。
- `source.rawData` 只供 Provider 调试和自身维护，页面不直接渲染。

## 2. 页面能力总表

| 页面/区域 | `pageKey` | `moduleKey` | Provider 方法 | 核心响应 |
|---|---|---|---|---|
| 首页轮播 | `home` | `banners` | `fetchData` | `items` |
| 首页热门电影 | `home` | `hotMovies` | `fetchData` | `items + pagination` |
| 首页热门电视剧 | `home` | `hotTv` | `fetchData` | `items + pagination` |
| 首页电影排行榜 | `home` | `movieRanking` | `fetchData` | `items` |
| 首页电视剧排行榜 | `home` | `tvRanking` | `fetchData` | `items` |
| 电影筛选 | `movie` | 空字符串 | `fetchFilterMeta` | `groups` |
| 电影目录 | `movie` | 空字符串 | `fetchData` | `items + pagination` |
| 电视剧筛选 | `tv` | 空字符串 | `fetchFilterMeta` | `groups` |
| 电视剧目录 | `tv` | 空字符串 | `fetchData` | `items + pagination` |
| 搜索结果 | `search` | 空字符串 | `fetchData` | `items + pagination` |
| 详情 | `detail` | 空字符串 | `fetchData` | `item` |
| 播放 | `player` | 空字符串 | `fetchData` | `item` |

个人中心的收藏和历史不是 Provider 页面桶。它们来自浏览器持久化的用户快照，并在需要时使用当前 Provider 补全详情或引导重新搜索。

## 3. 标准请求

`SourceDataRequest` 顶层固定包含：

| 字段 | 类型 | 作用 |
|---|---|---|
| `sourceId` | `string` | 当前请求必须使用的数据源身份。 |
| `pageKey` | `string` | `home/movie/tv/search/detail/player`。 |
| `moduleKey` | `string` | 首页区域键；其它页面为空字符串。 |
| `params` | `object` | 当前页面真实使用的参数。 |

常用 `params`：

| 字段 | 页面 | 规则 |
|---|---|---|
| `page` | 首页区域、电影、电视剧、搜索 | 从 1 开始的正整数。 |
| `pageSize` | 列表页面 | 电影 12、电视剧 18、搜索 12；首页由区域请求决定。 |
| `keyword` | 搜索 | 清理首尾空白后的非空关键词；空关键词不创建请求。 |
| `category/genre/year/status/area/sort` | 电影、电视剧 | 值必须来自当前 Provider 返回的筛选选项；未选中使用空字符串。 |
| `contentId` | 详情、播放 | 原样使用卡片 `ContentItem.id`，平台不拆解。 |
| `playbackSourceId` | 播放 | 目标 `playCatalog.lines[].id`；空值表示采用默认线路。 |
| `episodeId` | 播放 | 目标逻辑剧集 id；跨线路同一集应保持相同 id。 |
| `episodeIndex` | 播放兼容定位 | 没有稳定 id 时的可选序号，不得替代 Provider 稳定身份。 |
| `autoplay` | 播放 | 是否尝试自动播放；最终仍受浏览器策略限制。 |
| `requestPurpose` | 播放 | `playback` 解析正式媒体，`probe` 只做无视觉可达性探测。 |

筛选请求使用 `SourceFilterMetaRequest`，包含 `sourceId`、`pageKey` 和当前已选 `params`。Provider 可以根据已选项返回联动选项，但不能要求页面理解源站参数名。

## 4. 标准响应

`SourceDataResponse` 固定回填 `sourceId/pageKey/moduleKey/request`，并按页面提供：

- 列表页面：`items` 数组，`item` 为 `null`。
- 详情和播放：`item` 为一个 `ContentItem`，`items` 为空数组。
- 有分页页面：提供 `pagination`；无分页页面使用 `null` 或契约允许的空分页。
- `meta` 只保存标准附加信息，不允许页面读取源站私有结构。
- `updatedAt` 使用可解析时间字符串，表示本次标准响应生成时间。

分页对象至少表达当前页、每页数量、是否存在上一页和下一页；Provider 有可靠总数时再提供总条数和总页数。不能用当前数组长度伪造源站总页数。

筛选响应 `SourceFilterMetaResponse.groups` 每组包含稳定 `key`、显示 `label`、选项列表和当前值。每个选项包含 Provider 可识别的稳定 `value` 与用户可读 `label`；“全部”使用平台约定的中性值，不把站点 URL 暴露给页面。

## 5. ContentItem

### 5.1 最小身份

以下字段必填：

| 字段 | 作用 |
|---|---|
| `id` | 当前 Provider 内稳定内容 id，用于详情和播放续请求。 |
| `sourceId` | 必须等于本次响应所属数据源。 |
| `type` | `movie` 或 `tv`。 |
| `title` | 卡片、详情和播放标题。 |

`sourceName` 应与当前 SourceDefinition 名称一致。界面统一截断展示名称，Provider 不拼接域名、版本或“数据源”后缀。

### 5.2 卡片与基础元信息

| 字段 | 展示位置 | 空值行为 |
|---|---|---|
| `poster` | 视频卡片、搜索、收藏、历史 | 无图时使用平台空图状态，不显示破损地址。 |
| `cover` | 首页轮播、详情背景、播放背景 | 可回退 `poster`，两者都空则使用无媒体背景。 |
| `description` | 轮播和列表摘要 | 为空时隐藏摘要。 |
| `year/area/language` | 卡片元信息、搜索、详情 | 单项为空即跳过，不保留空分隔符。 |
| `genres` | 卡片与详情类型标签 | 空数组时隐藏。 |
| `tags/displayTags` | 推荐、排行和轻量状态 | 不替代类型、清晰度或评分。 |
| `score` | 卡片和排行 | `null` 时隐藏，不能用 0 表示未知。 |
| `quality` | 卡片角标、电影资源 | 空时隐藏。 |
| `badge` | 卡片图片角标 | 空时隐藏。 |
| `rank` | 排行榜 | 非榜单或未知时为 `null`。 |
| `movie.duration` | 电影卡片和详情 | 空时隐藏，显示由平台统一格式化。 |
| `tv.updateStatus` | 电视剧卡片和详情 | 可显示“更新至…”或“全…集”；空时再参考明确集数字段。 |

卡片不会从标题、简介或 `source.rawData` 猜测缺失字段。Provider 应保留源站卡片上可以可靠确定的全部标准信息，即使当前页面暂时不展示。

### 5.3 详情字段

详情请求应尽力补齐：

- `originalTitle`、`aliases`。
- `detail.fullDescription`，为空时页面回退 `description`。
- `detail.directors/writers/actors`。
- `detail.releaseDate/updateTime/status`。
- `detail.screenshots/trailerUrl`，只有真实可用时提供。
- 电影 `movie.duration`，电视剧 `tv.totalEpisodes/latestEpisode/updateStatus/season`。
- 全部真实 `playCatalog` 线路和分集。

字段不存在时对应信息行隐藏。页面不会把一段源站“其它信息”拆成导演、演员或状态，也不会在公共代码中写站点选择器。

## 6. 首页

### 6.1 轮播 `banners`

优先消费 `cover`，可回退 `poster`；显示 `title/description/badge/score/genres` 中非空字段。点击使用 `sourceId + id` 进入同源详情。平台允许保存较多轮播候选，但实际显示数量由用户首页设置决定。

### 6.2 热门电影 `hotMovies`

只返回 `type=movie` 的卡片，提供分页时页面可以继续请求。优先展示 `poster/title/year/area/genres/score/quality/movie.duration`。

### 6.3 热门电视剧 `hotTv`

返回 `type=tv` 内容。`year/area/genres/tv.updateStatus/tv.latestEpisode` 用于元信息与更新角标；Provider 可以在标准 `genres/tags` 中提供综艺、动画等语义，不要求公共页面识别站点导航名称。

### 6.4 排行榜

`movieRanking` 与 `tvRanking` 需要稳定顺序。Provider 有真实排名时填写 `rank`；未填写时页面可按当前数组顺序展示，但不能把这个显示序号保存为内容身份。

## 7. 电影与电视剧目录

电影目录默认请求每页 12 条，电视剧目录默认每页 18 条。两页都先请求筛选元数据，再把用户选择的标准值传给 `fetchData`。

Provider 可以把源站多个固定板块合并成一页，但必须自己完成稳定排序、逻辑分页和筛选映射。页面只认标准 `items/pagination/groups`，不会循环调用站点标签或拼接站点 URL。

没有筛选项时返回空 `groups`，目录仍可请求默认列表。某个筛选组合没有结果时返回成功空数组，而不是伪造错误。

## 8. 搜索

搜索只对非空 `keyword` 发起请求，默认每页 12 条。每一条结果必须有稳定 `id/sourceId/type/title`，类型判断和源站分页由 Provider 负责。

- 有结果：返回 `items + pagination`。
- 当前页无结果且查询合法：返回成功空数组。
- 源站挑战、运输或解析失败：抛出稳定 Provider 错误，不返回旧页结果冒充成功。
- 搜索结果进入详情后仍使用原结果的 `sourceId`，不会自动切到当前导航中的其它源。

## 9. 详情

详情请求使用 `contentId` 返回单个 `item`。返回标题必须与被请求内容身份一致，Provider 自己排除同名搜索中的其它作品。

`playCatalog` 是详情页和播放页唯一线路/选集权威：

```text
playCatalog
├─ defaultLineId
└─ lines[]
   ├─ id / name / available / unavailableReason
   └─ episodes[]
      ├─ id / kind
      ├─ seasonNumber / episodeNumber / title
      ├─ label / duration / description / cover
      └─ playable
```

详情页以线路下拉框和当前线路回显展示目录。电影通常每条线路只有一个 `kind=feature` 条目，按钮显示 Provider 提供的 `label`，例如“HD”或“正片”；电视剧显示该线路真实提供的分集。

详情页可以探测线路代表分集的可达性，但不会把临时探测状态保存进 ContentItem，也不会删除目录条目。未探测、正在探测和无法判定不等于 Provider 声明的永久不可用。

## 10. 播放

播放请求必须返回同一内容的完整 `playCatalog`，并只在 `playback` 中提供当前 `lineId + episodeId` 已解析成功的一个媒体：

```text
playback
├─ lineId
├─ episodeId
└─ media
   ├─ type: mp4 | hls
   ├─ url: HTTPS 直连地址
   ├─ quality
   └─ deliveryMode: direct
```

禁止把 Cookie、Token、自定义请求头、源站播放页、代理 URL 或其它线路媒体放入 `playback.media`。目标媒体无法解析时请求失败，播放页仍保留内容壳、线路和选集，方便用户改选。

线路切换规则由平台按逻辑剧集 id 执行：同一集在新线路存在时可继续播放并恢复该集历史；新线路缺少当前集时只切换选集列表并提示用户手动选集，正在播放线路回显保持不变。

## 11. 个人中心与设置

### 11.1 收藏和历史

个人中心卡片来自持久化 `ContentCardSnapshot`，保存内容身份、标题、图片、基础元信息、来源显示和恢复定位。即使 Provider 被删除，记录仍保留；点击失效记录会进入跨源搜索恢复流程。

播放历史按同一来源内容和逻辑剧集维护进度，并保留最近成功线路。平台不会要求 Provider 返回“历史页面”数据桶。

### 11.2 设置页

- 数据源管理：平台拥有导入、授权、启停、默认源、更新和缓存操作。
- 系统源致谢声明：只展示 `sourceKind=system` 的标准署名投影。
- 自定义源责任声明：只展示 `sourceKind=custom` 的标准署名投影。
- 关于：展示项目许可证、仓库和主要直接开源项目。

Provider 只能通过 manifest/Definition 提供脚本名称、版本、作者、站点名称、站点地址和声明，不控制设置页布局、平台用户状态或项目许可证。

## 12. 页面请求状态

每个页面桶都有独立请求事务：

| 状态 | 页面行为 |
|---|---|
| `idle` | 尚未请求；显示初始空状态，不冒充加载失败。 |
| `loading` | 显示加载状态；切源后旧源内容标记 `stale` 并隐藏。 |
| `success` | 一次采用最新请求的实体、分页和请求回填。 |
| `empty` | 不是独立事务状态；`success` 且当前 items 为空或 item 不存在时由 selector 投影为空内容界面。 |
| `error` | 显示稳定错误和重试入口；旧实体可留作诊断，但不能显示为当前结果。 |
| `stale=true` | 当前桶内容与请求来源或最新身份不一致，selector 必须隐藏。 |

请求完成采用还要求 `requestId`、页面桶和真实 `resolvedSourceId` 全部匹配。迟到响应不能覆盖新数据源或新页面请求。

## 13. 空值与失败清单

- 可选字符串为空：隐藏字段和分隔符。
- 可选数组为空：隐藏对应标签或人员区。
- `score/rank/totalEpisodes/latestEpisode` 未知：使用 `null`，不要伪造 0。
- 列表成功但无结果：返回空 `items`，页面显示空状态。
- 详情没有匹配内容：抛出稳定未找到错误，不返回搜索中的其它标题。
- 播放媒体解析失败：抛错并保留页面可切换目录，不返回空媒体覆盖旧会话。
- 源站挑战：通过 SourceContext challenge 能力处理，不把验证码 HTML 当内容。
- Provider 不可用：健康状态变红；页面请求错误与健康状态分别保存，不能互相冒充。

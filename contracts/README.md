# 公共协议契约向量

本目录保存前端、后端和 Provider 共同使用的语言无关协议向量。它们属于协议核对资产，不是应用运行时业务代码，也不是供人工复制的 JavaScript 样板；公开字段和错误语义由当前向量与 [数据源脚本开发指南](../docs/数据源脚本开发指南.md) 共同说明。

## 目录职责

| 目录 | 职责 | 当前实现是否读取 |
|---|---|---|
| `current/` | 当前有效的 Proxy Protocol、Provider ABI 和 manifest schema 契约向量 | 是 |

当前实现和公开开发文档只引用 `current/`。已退出版本由 Git 提交与发布标签追溯，不在公开源码树保留第二份历史向量，也不能把旧版本重新解释为当前兼容输入。

## 升级规则

发布新的不兼容协议版本时，先在发布提交或标签中冻结现有 `current/` 文件与 SHA-256，再原子替换整个 `current/`。公开源码树只保留当前版本，旧路径不保留转发文件、软链接或副本。
